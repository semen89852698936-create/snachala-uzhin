## Принцип качества

Выбрана редакционная эстетика: натуральный свет, уютная керамическая посуда, приятная теплая нейтральная цветовая палитра и реалистичная фактура блюд. Не принимать неправильную форму пасты, неподходящий вид мяса, отсутствие ключевого компонента или нерелевантный гарнир только ради красивой фотографии.

Все страницы кандидатов необходимо проверить по оригиналу на соответствие ингредиентам, достаточную ширину/высоту, кадрирование и лицензию. Pexels License обычно допускает коммерческие сайты, но требуется соблюдать ограничения и не вводить в заблуждение относительно происхождения или автора. См. https://www.pexels.com/legal-pages/license/ и https://www.pexels.com/api/documentation/.

## Масштабирование без платной AI-генерации

`photo-pipeline/pexels_search.py` готовит кандидатов через официальный бесплатный Pexels API:

- Явно требует `PEXELS_API_KEY` в GitHub Secrets (можно оформить на https://www.pexels.com/api/).
- По расписанию, после слияния кода и включения `PHOTO_STOCK_SEARCH_ENABLED=true`, проверяет **до 40 ещё не обработанных рецептов** за один часовой запуск.
- Индексирует результаты в ветку `photo-library/stock-discovery`. Ссылки и миниатюры **не считаются готовыми** фотографиями.
- Не скачивает изображения автоматически, не одобряет их и не меняет production.
- По тарифу Pexels API доступен бесплатно, обычные лимиты 200 запросов/час и 20 000 запросов/месяц; соблюдать условия API, включая ссылки и атрибуцию.
- Отдельно подготовлена AI-генерация, но она полностью заблокирована по умолчанию пустым `ai-allowlist.json` и защитными флагами. В AI-очередь заносить лишь рецепты, для которых настоящие фотографии не были найдены после редакционной проверки.

## Следующая производственная операция

1. Подключить бесплатный Pexels API через секрет GitHub (не передавать ключ в чат).
2. Проверить и слить draft PR после тестов.
3. Активировать только `PHOTO_STOCK_SEARCH_ENABLED` для бесплатного поиска, без разрешения платной AI-генерации.
4. Визуально отобрать лучшие фото, затем скачивать и сохранять выбранные с авторством и контрольными суммами.
5. Возвращаться к AI только после настоящей проверки оригинальных фотокандидатов.
