# Фотобиблиотека «СНАЧАЛА УЖИН»

Статус на 2026-11-01: **1001 рецептов, 0 локальных фото, 0 утверждённых**. На опубликованном сайте используются 17 повторяющихся внешних идентификаторов изображений, это не уникальная библиотека.

## Источники
- `recipes-photo-registry.csv`: все 1001 рецептов, `status` и `review_status` отдельно.
- `curated-images.json`: кандидаты с точной страницей источника, автором, лицензией и результатом визуального отбора. Это **не файлы фотографий**.
- `summary.json`: счётчики; кандидаты не повышают `generated` и `approved`.

## Порядок отбора
1. Брать первую партию с `status=pending` и без `review_status` или с отметкой необходимости повторного поиска.
2. Находить конкретную страницу изображения, проверять автора и текст лицензии, сохранять источник и условия атрибуции.
3. Смотреть **именно это** изображение, сравнивать с реальным составом блюда и эталоном: ресторанная подача, мягкий свет, романтическая атмосфера, хорошая резкость.
4. Отклонённые и пригодные только для шагов фотографии не использовать в качестве основного фото рецепта.
5. Скачивать оригинал только при доступном безопасном канале и фиксировать файл, контрольную сумму, авторство и условия использования. Отдельно проверять юридические нюансы лицензии.
6. Считать фото утверждённым только при существовании локального файла, пройденной визуальной проверке и правовом допуске. Никогда не выдавать ссылку, превью или текстовый промпт за готовое фото.
7. Публиковать только после проверки в отдельном тестовом окружении и разрешения владельца.

## Проверка
```bash
node --test photo-library/tests/validate-registry.test.mjs
node photo-library/validate-registry.mjs
```

Для CC BY обязательны имя автора, ссылка на оригинал, лицензия и информация об изменениях; для CC BY-SA требуется также проверить условия ShareAlike. Сверка заявленной лицензии на Commons не заменяет юридическое заключение.

## Текущий результат
Первая партия: рецепты 1–20. Просмотрено 7 фотокандидатов для рецептов 7, 9, 17. Сверены заявленные лицензии, все 7 визуально оценены, но ни один не соответствует уровню главного фото. Один крупный план фокаччи можно рассмотреть для иллюстрации шага. Остальные 17 рецептов партии ждут поиска. Дальнейшая работа должна уделять приоритет поиску действительно качественных фотографий, а не заполнению каталога любой ценой.
