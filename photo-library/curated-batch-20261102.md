# Настоящие фотографии: отобранная партия из 12 файлов

Эта партия **содержит реально сохранённые** WebP (1200×900) из уже созданного архива. Они были визуально просмотрены по изображению, а не только по названиям. **Их не нужно генерировать или оплачивать повторно.**

Файлы: `assets/recipes/*.webp`. Машинный список, привязка к рецептам, ссылки на оригиналы и лицензии: `photo-library/curated-batch-20261102.json`.

Не заявляем точное совпадение всех дополнительных ингредиентов; статус «подходит по блюду, второстепенные детали могут отличаться». Для публикации на коммерческом сайте сверить правомерность использования оригинала и интеграцию с каталогом.

Важно: до изменения карточек каталога и проверенного деплоя на Vercel эту партию нельзя называть опубликованной.
