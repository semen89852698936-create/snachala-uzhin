# СНАЧАЛА УЖИН — архив 20 рецептов и 20 фотографий

**Срез на 14 ноября 2026 года. Ни один рецепт на действующем сайте не заменён.**

**Как устроено:** в каждом из двадцати пронумерованных каталогов находится ровно два независимых файла: `photo.webp` и `recipe.md`. У них один постоянный ID, совпадающий с названием папки. Не переносить изображения по порядку отдельно от рецептов.

- `01_PLOV` — десять пловов; исходные фото из Alice AI ART, визуальная приёмка этих десяти по отдельности ещё требуется.
- `02_NEW_DISHES` — десять блюд новой партии; **четыре фотографии из коллажа 2×2 утверждены владельцем и перенесены дословно без перегенерации**, шесть остальных сохраняют свои текущие статусы проверки.
- `INDEX.csv` — точное сопоставление названий, ID, путей, статусов и будущих замен.
- `MANIFEST.json` — машинно читаемый реестр, содержит исходные Git blob SHA каждого фото и поля `replace_recipe_id: null` до указаний владельца.

## Будущее размещение

Целевой размер существующего каталога — **1001 рецепт**. Пловы задуманы как замена десяти существующим в «Мясо». Какие именно карточки заменяются и как распределяется новая партия, пока не определено. Ничего не удалять автоматически.

Если менять рецепты на сайте, сначала выбрать **конкретные существующие ID**, затем заменить по одной паре `(recipe.md, photo.webp)` и проверить счетчик, поиск, любимые, покупки, пошаговую готовку и адаптивность.

**Источник:** редакционные JSON-файлы проекта на GitHub и действующие по состоянию на эту дату изображения из соответствующих рабочих веток. Содержание рецептов при экспорте не исправлялось.
