# СНАЧАЛА УЖИН

Самостоятельный репозиторий кулинарного сайта. Исходная демоверсия перенесена из ветки `snachala-uzhin-site` репозитория `granitsy-semen-chayka-` 31.10.2026, без изменения утверждённого визуального оформления.

## Что уже есть
- `index.html`, `favicon.svg`, `robots.txt`, `server.py`, `Dockerfile`: исходники демоверсии.
- 20 основных рецептов и 1 бонус. **Это не полный каталог на 1001 рецепт.** Заявленные 980 рецептов ещё не созданы и не проверены.
- `music/README.md`: 3 тематических списка по 10 треков.
- `music/spotify-playlists.json`: все три настоящие ссылки плейлистов Spotify.
- `music/spotify-embed.html`: заготовка встроенных Spotify-плееров, требующая интеграции в сайт.

## Работающий сайт
Импорт в GitHub пока не меняет действующий сайт на Vercel. Перед публикацией требуется проверка и привязка отдельного проекта Vercel к этому репозиторию. Не заменяйте полную версию на 21-рецептную демоверсию.

## Правки каталога
Надпись «Домашняя» найдена в описании рамена и **не является универсальным ярлыком карточек этой демоверсии**. Для изменения характеристик полного каталога нужны исходники полной версии. Не заменять текст в описаниях блюд без проверки смысла.

## Перед коммерческим запуском
Проверить рецепты, права на изображения и музыку, каталог, мобильную версию и платежную систему. Оплата в демо отключена.
