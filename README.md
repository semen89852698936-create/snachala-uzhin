# СНАЧАЛА УЖИН

Восстановленный кулинарный проект.

## Состояние на 31 октября 2026
- Основной `index.html` восстановлен из опубликованной версии `snachala-uzhin-preview.vercel.app` и содержит **1001 запись рецептов** с уникальными идентификаторами.
- До переноса в этом репозитории была демоверсия с 20 рецептами и бонусом. Её версия сохранена в истории Git.
- Неизменённый снимок полной опубликованной версии хранится в `full-catalog/index.html`.
- В рабочий `index.html` добавлены три встроенных Spotify-плейлиста, ссылки продублированы в `music/spotify-playlists.json`.
- **Проблема изображений не решена:** в 1001 рецепте используются лишь 17 разных `photo` идентификаторов. Требуется покарточная проверка и замена на соответствующие блюда лицензированные изображения.
- Наличие 1001 записи не равно редакционной или кулинарной проверке каждого рецепта. Составы, технологии и фотографии требуют контроля качества.
- **Изменения ещё не опубликованы на Vercel.** Прежде чем менять существующую production-версию, проверить новый HTML на тестовом развёртывании.
- Платёжные функции не активировать до проверки контента, прав, юридических условий и технической части.
