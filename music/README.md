## Для подключения к сайту
1. Создать три плейлиста в Spotify, добавить выбранные записи (сверить исполнителя и версию).
2. Скопировать ссылки плейлистов вида `https://open.spotify.com/playlist/<ID>`.
3. Вписать ссылки в `music/spotify-playlists.json`.
4. Встроить официальные Spotify iframe-плееры в раздел сайта, заменив только музыкальный контент.

Примечание: это подготовленные списки, а не уже созданные плейлисты в аккаунте Spotify. Полное воспроизведение через Embed зависит от условий доступа слушателя Spotify. В репозитории сейчас нет исходников опубликованного сайта, поэтому работающий сайт не изменён.
