# Продюсер 24/7: безопасный прототип

Цель: независимый от чата исполнитель для проектов «СНАЧАЛА УЖИН», «Наш вечер» и будущих продуктов. На первом этапе **только аудит**, без автономной публикации.

Рабочий цикл: получить задачу -> проверить состояние проекта -> исполнить ограниченное действие -> тесты -> отчёт -> проект PR -> отдельное подтверждение человеком -> публикация. Агент может делать безопасные изменения лишь в отдельных ветках, не в main.

Текущий реализованный уровень: `producer/inspect.py` читает каталог 1001 рецепта, проверяет состояние фотобиблиотеки и присутствие файлов страниц. Workflow `.github/workflows/producer-safe-audit.yml` может сохранять отчёт в GitHub Actions Artifacts. Он не генерирует изображения и не исправляет код посредством LLM.

ВАЖНО: расписание GitHub Actions работает **только из default branch**. Этот файл пока находится в непубликуемой feature-ветке и не является включённым круглосуточным агентом. Для настоящей автономной генерации контента и разработки потребуется подключение API модели, лимиты расходов, защищённые secrets, список разрешённых действий, защита PR и контроль качества. Публикация только с явным согласованием.

Границы: запрещены автоматический merge, production deploy, покупка ресурсов, удаление рабочих данных, изменение доменных настроек и отправка внешних материалов без одобрения владельца.
