# НАШ ВЕЧЕР · 100 салатов мира

Рабочая редакционная ветка `editorial/world-salads-100-20261119`.

- **100 самостоятельных карточек**: 10 кухонь по 10, каждая на **2 порции**; у каждой есть ингредиенты в единицах измерения, пошаговая технология, время и ориентир для фотосъёмки.
- Файлы расположены в `data/editorial/salads/` (10+30+30+30). Проверка структуры: `node scripts/check-world-salads-100.cjs`.
- **Статус:** редакционные черновики, **не пройдена покарточная проверка национальных первоисточников**, не утверждены пользователем.
- **Изображения:** отсутствуют 100 отдельных одобренных фото. В каждой карточке `photoStatus=pending_separate_photo`, поле `photo` намеренно отсутствует, чтобы не подменять изображения старых утверждённых блюд.
- **Публикация:** НЕ выполнена. `index.html`, `full-catalog/index.html`, работающие категории, существующие карточки, фотографии и эталонный публичный Vercel не менялись.
- **Обязательный следующий этап до публикации:** независимо сверить каждую национальную рецептуру с авторитетными кулинарными источниками, проверить рискованные технологии (морепродукты, солёная треска, рыба, мясо); подготовить 100 новых фотографий строго по готовому блюду; аккуратно сопоставить старые IDs, не стирая утверждённые карточки; запустить CI и визуальную приёмку всех 100 карточек в обеих HTML-версиях.

Ни этот статус, ни успешный структурный тест **не означает**, что все рецепты кулинарно проверены или опубликованы.
