# Поиск фотографий для всех 1001 рецептов

## Статус
Создан воспроизводимый инструмент подготовки очереди исследований: `tools/build_photo_queue.py`.
Это **не** готовый набор 1001 проверенных фотографий. Никакие фотографии не заменены на сайте.

## Использование
Из корня репозитория:
```bash
python3 tools/build_photo_queue.py
```
Скрипт извлекает реальные названия и ID рецептов из `index.html`, проверяет количество/уникальность ID и создаёт `audit/photo-research-queue.csv` с поисковыми ссылками для Wikimedia Commons, Pexels и Unsplash по каждой позиции.

## Как принимать фотографию
1. Визуально сравнить изображённое блюдо с заголовком, ингредиентами и способом приготовления.
2. Открыть оригинальную страницу фотографии, зафиксировать `candidate_url`, автора, лицензию, ссылку на подтверждение разрешения.
3. Проверить правовой статус, товарные знаки и лица (если есть).
4. Пометить `visual_match` как yes/no и `approval_status` как approved/rejected/needs_review.
5. Не принимать общее изображение категории в качестве фото конкретного блюда.
6. После принятия провести тест загрузки, размеров, адаптивной вёрстки и только после этого готовить замену.

## Важные ограничения
- Pexels: https://www.pexels.com/legal-pages/license/
- Unsplash: https://unsplash.com/license
- Wikimedia Commons: на каждой странице файла могут быть разные условия лицензии и атрибуции.
- Поисковые ссылки не равны найденным и лицензированным конкретным снимкам. Автоматический выбор без визуальной проверки запрещён.
- Рабочий сайт и production не изменяются.
