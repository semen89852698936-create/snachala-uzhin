# Десять рецептов плова - редакционная партия от 13.11.2026

## Состав и статус

- Источник: предоставленный пользователем файл `ПЛОВ.docx`, десять рецептов и десять встроенных скриншотов блюд.
- Данные: `data/plov-ten-editorial.json`; новые самостоятельные IDs, **по две порции**, точные количества, пошаговая готовка, работающие таймеры.
- Отдельная редакционная страница: `/plov/`. Сохраняет визуальный язык сайта, не меняет утверждённые страницы.
- Существующий каталог из **1001 рецепта не изменён**. Не менять счётчик на 1011, не заменять десять утверждённых позиций без отдельного решения.
- Фотографии: новые, индивидуальные WebP 1200×900 из **Alice AI ART**. Скриншоты из источника используются **только как образцы композиции**. Не загружать скриншоты на сайт и не повторять чужие картинки один в один.
- Конвейер: `photo-pipeline/generate_plov_batch.py`, GitHub Actions `yandex-ai-plov-ten.yml`; максимум десять платных вызовов, с фиксацией резервирования до каждого запроса.
- Производственная ветка снимков: `photo-production/plov-ten-20261113`; оттуда переносить изображения в рабочую ветку **только после проверки десяти файлов**.
- Публикация на текущем публичном домене не выполнена. Основная ветка, эталон `ac1651a2a0c8f03276872c907422eb2d58d1154c`, музыкальный плеер, четыре кнопки, фотографии «Нашего вечера» не затронуты.
- Утверждение новых фотографий пользователем требуется отдельно. После просмотра можно менять только конкретно отвергнутые снимки.

## Приёмка до публикации

1. Десять индивидуальных фотографий есть физически в `assets/plov`, технически читаются, не подменены скриншотами из Word.
2. Для каждого снимка подтверждено визуальное соответствие рецепту, реальная текстура готового блюда; не должно быть целого чеснока и ингредиентов, отсутствующих в рецепте.
3. Запущены `node scripts/test-plov-10.cjs` и Python prompt dry-run.
4. Проверены 10 карточек, мобильная/десктопная вёрстка, закрытие модального окна, один шаг за раз, таймеры и открытие ссылок.
5. Публикация на основной адрес только после проверки и решения, как эта подборка должна открываться из навигации сайта. Не менять утверждённые кнопки самовольно.
