# Новые блюда: редакционная подборка из десяти рецептов (13.11.2026)

## Назначение и границы

- Источник: пользовательский DOCX `Новые блюда.docx`, 16 страниц, **10 рецептов и 10 фото-образцов** с водяными знаками стороннего кулинарного ресурса.
- Каждое фото исходника предназначено исключительно для изучения состава и подачи; **не копировать и не публиковать изображения/скриншоты из DOCX**.
- Данные в `data/ten-new-dishes-editorial.json`: 10 отдельных ID, **две порции**, структурированные продукты с единицами, авторская русская редактура, шаги и минуты таймеров, фотобриф каждого блюда.
- Экспериментальная страница `/new-dishes/` стилизована по существующему оформлению «СНАЧАЛА УЖИН», использует детальную карточку и пошаговый режим с таймерами.
- Оригинальные фотографии готовых блюд генерирует Alice AI ART через `photo-pipeline/generate_new_dishes_batch.py`, GitHub workflow `.github/workflows/yandex-ai-new-dishes-ten.yml`. Запрещены копии исходников, надписи, водяные знаки, ингредиенты не из рецепта.
- **Нет разрешения на замену каких-либо рецептов основного каталога**. Пользователь отдельно сообщит, какие карточки заменять. Количество опубликованных рецептов обязано оставаться **ровно 1001**.
- Для первого этапа жюльен помечен `poultry`, другие 9 как `meat` (классификация фактических блюд в отдельной подборке, **не решение о конечном разделе на сайте**).
- Нельзя затрагивать ветку утверждённого эталона `approved/FINAL-snachala-uzhin-2026-11-12-player-title-fixed` и визуальные блоки основного сайта, музыку, «Наш вечер», существующие фотографии.
- После полной генерации фото и визуальной приёмки выбрать будущие 10 удаляемых карточек вместе с пользователем; провести интеграцию на новую рабочую ветку с сохранением ID и списка покупок. Пока ничего не заменять в `index.html` и `full-catalog/index.html`.

## Редакторские восстановления, не буквально из источника

- Жаркое: указание после «накрыть крышкой, убавить огонь и тушить на» отсутствует; ориентир **35 минут** для тушения на двоих выбран редакционно.
- Гуляш: в исходнике после добавления паприки отсутствует явный переход «добавить мясо», хотя дальнейший текст его подразумевает; восстановлен логичный шаг.
- Шашлык: количества продуктов, режим температуры духовки не указаны; редакционные ориентиры на двоих 500 г мяса, 300 г лука, 2 ст. л. 9%-го уксуса, 200 °C с учётом инструкции к рукаву. Мариновать в холодильнике.
- Бефстроганов с грибами: для короткого обжаривания на сковороде предложена говядина **мягкого отруба**; при другом отрубе нужно увеличивать тушение.
- Жюльен: сковородная версия из источника, не духовка; сыр плавится под крышкой. Курицу готовить до 74 °C.

## Проверка перед публикацией

1. Node-тест `node scripts/test-new-dishes-10.cjs` подтверждает 10 различных ID, структуру ингредиентов, 2 порции, соответствие страниц источника и таймеры.
2. Бесплатный Python dry-run всех 10 промптов, затем генерация индивидуальных WebP; контрольная запись с SHA256 и подписью генератора для каждой фотографии.
3. Визуальный просмотр 10 кадров, исправление неточных изображений по согласованию, без подмены фото из источника.
4. Desktop/mobile QA карточек, корректных шагов, таймеров, закладок, поиска после интеграции.
5. **Обязательный отдельный этап** - замена строго выбранных пользователем рецептов с проверкой, что каталог по-прежнему содержит **1001**, без изменений утверждённого дизайна.
